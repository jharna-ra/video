White Text Removal

Draw the box around the text. Only thin, pure-white strokes (letters) are changed — everything else in the box stays identical to the original video. Tick Show detected text in red to see exactly which pixels will be removed: if red covers the text, you are set; if red covers other things, raise the sensitivity number; if letters are not fully red, lower it (or raise Max text stroke thickness for bold text).
