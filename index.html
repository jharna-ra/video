Every pixel is judged on its own color: clearly-white pixels are always removed; fainter blended pixels are only removed if they actually touch a detected white pixel (real anti-aliased edge), not just "nearby" — no blind radius/halo involved. This slider sets how faint a touching pixel can be and still count. Also pulls in any dark outline/shadow stroke directly hugging the letters, so the whole glyph disappears, not just its white fill. Lower the sensitivity number above if text is still visible.
If text is still visible even at full strength, it usually means those pixels aren't being classified as "white" — a common case is reflective/light text printed directly on a strongly colored background (like a number on a yellow safety vest), since the detector deliberately avoids erasing saturated colors so it doesn't eat holes in vests/signage. Tick this BEFORE drawing a box to skip color detection completely for that box and erase everything inside it, guaranteed — regardless of color. This is set per box: leave it off for boxes over plain backgrounds (so removal stays clean and precise), and turn it on only for stubborn boxes like text-on-colored-background.
